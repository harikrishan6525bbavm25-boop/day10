# Day 10 — Lab 10: Aviation Image Generation

## 📌 Overview

This lab focuses on using **AI image-generation tools to create realistic and professional aviation visuals** through structured prompting. The activity demonstrates how prompt quality affects generated images and how aviation visuals should be reviewed for accuracy, professionalism, safety, branding, privacy and ethical concerns.

The lab covers weak versus structured prompts, single-variable refinement, prompt bleed, aviation accuracy auditing, professional evaluation, business-use aviation visuals, responsible AI use and human review.

---

## 🎯 Objectives

The main objectives of this lab were to:

* Understand the components of an effective image-generation prompt.
* Compare weak and structured image prompts.
* Generate professional aviation visuals.
* Refine images by changing one variable at a time.
* Identify prompt bleed and unwanted visual effects.
* Check aviation realism and operational accuracy.
* Avoid logos, personal information and misleading text.
* Evaluate AI-generated images for professional use.
* Understand ethical and responsible AI image generation.
* Apply human review before publication.

---

## 🧩 Five-Part Image Prompt

The lab identifies five important components of an effective image prompt:

| Component          | Purpose                                           |
| ------------------ | ------------------------------------------------- |
| **Subject**        | Defines what should appear in the image           |
| **Medium / Style** | Defines the visual style                          |
| **Environment**    | Specifies the location and surroundings           |
| **Lighting**       | Controls the visual atmosphere                    |
| **Aspect Ratio**   | Defines the image composition and intended format |

These five components provide clearer instructions to an image-generation system.

# 🔬 Single-Variable Refinement

The lab tested image refinement by changing **one variable at a time**. This makes it easier to identify which instruction caused a change in the generated image.

### Version 1 — Style Change

**Changed:** Photorealistic image → Clean flat-vector illustration

**Expected effect:** A more graphical and simplified appearance.

**Actual effect:** People, kiosks and the terminal became more stylised and simplified.

**Unexpected effect:** Some realistic airport details were reduced.

### Version 2 — Lighting Change

**Changed:** Bright natural daylight → Warm evening lighting

**Expected effect:** A warmer and more atmospheric terminal.

**Actual effect:** The environment became warmer and closer to an evening setting.

**Unexpected effect:** Some areas became darker, reducing visibility of small airport details.

### Version 3 — Aspect Ratio Change

**Changed:** 16:9 landscape → 1:1 square

**Expected effect:** A compact composition suitable for social media.

**Actual effect:** Main subjects became more centrally positioned.

**Unexpected effect:** Some background and peripheral airport elements were cropped.

### Version 4 — Environment Change

**Changed:** Self-service check-in area → Boarding-gate waiting area

**Expected effect:** A boarding-gate passenger waiting scene.

**Actual effect:** The environment changed to a passenger waiting area.

**Unexpected effect:** The self-service technology focus became less prominent.

# 🎨 Prompt-Bleed Analysis

Prompt bleed occurs when one instruction unintentionally affects another part of the generated image.

Examples identified in the lab include:

| Prompt Instruction      | Possible Unwanted Effect             | Corrective Instruction                          |
| ----------------------- | ------------------------------------ | ----------------------------------------------- |
| Blue-and-white palette  | Excessively blue objects or clothing | Use colours mainly for environmental accents    |
| Modern airport          | Excessively futuristic technology    | Use realistic current-generation infrastructure |
| Self-service technology | Artificial text on screens           | Keep screens blank/non-readable                 |
| Diverse travellers      | Unexpected appearance variations     | Use natural and realistic representation        |

# ⚠️ AI Image-Generation Limitations

The lab identified several limitations of AI-generated aviation visuals:

1. AI image generators can struggle with accurate readable text.
2. Hands, fingers and small facial details can contain inconsistencies.
3. Airport equipment and operational details require human checking.
4. Unwanted logos may potentially appear.
5. Generated people should be reviewed for unintended representation or stereotypes.
6. Background elements may appear automatically.
7. Photorealistic images may be mistaken for real photographs.
8. AI-use disclosure may be appropriate depending on the platform, organisation or intended use.

---

# 🔐 Ethical and Responsible AI Use

The lab highlights several ethical considerations:

* Do not present AI-generated images as authentic photographs of real events.
* Avoid unauthorised airline or airport branding.
* Avoid identifiable real individuals without appropriate permission.
* Review images for unintended stereotypes.
* Do not generate false safety information.
* Consider AI disclosure where required.
* Check usage rights and third-party rights before commercial publication.
* Conduct human review before using visuals publicly.

# 🧠 Key Learnings

### 1. Effective Image Prompting

A strong prompt should clearly define the **subject, style, environment, lighting and aspect ratio**.

### 2. Image Generation vs Image Retrieval

Image retrieval means finding an existing image, while image generation creates a new image from a text prompt.

### 3. Single-Variable Refinement

Changing one variable at a time makes it easier to understand which instruction caused a visual change.

### 4. Prompt Bleed

Prompt bleed occurs when an instruction unintentionally affects another part of the generated image.

### 5. Text Generation Limitations

AI image generators can struggle with accurate readable text, so important text should normally be added separately in a design tool.

### 6. Branding and Intellectual Property

Real airline logos should be avoided to reduce branding, permission and intellectual-property concerns.

### 7. Human Review

Even realistic-looking AI images can contain incorrect aviation details, so human review is necessary before publication.
